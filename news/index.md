# Changelog

## daisytools 1.0.0

- Renamed package from `daisyrVis` to `daisytools`.
- Improved `DESCRIPTION` metadata for CRAN readiness.
- Added broader API contract tests.
- Fixed header parsing and writing for round-tripping `.dlf` files.
- Fixed
  [`mass_balance()`](https://daisy-model.github.io/daisy-r-tools/reference/mass_balance.md)
  and
  [`mass_balance_summary()`](https://daisy-model.github.io/daisy-r-tools/reference/mass_balance_summary.md)
  for single-column inputs.
