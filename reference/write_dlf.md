# Write a dlf object to a file

Write a dlf object to a file

## Usage

``` r
write_dlf(dlf, path, sep = "\t", include_dlf_header = FALSE)
```

## Arguments

- dlf:

  Dlf object to write

- path:

  Output path to write to

- sep:

  Separator to use in csv file

- include_dlf_header:

  If TRUE write the Dlf header to the beginning of the csv file
